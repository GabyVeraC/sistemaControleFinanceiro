# 💰 Controle Financeiro

Sistema de controle financeiro desenvolvido em **Python** como parte do meu processo de aprendizado e construção de portfólio na área de desenvolvimento.

O projeto permite registrar receitas e despesas, acompanhar o saldo disponível e consultar o histórico de movimentações. Os dados são armazenados em um arquivo **JSON**, permitindo que as informações sejam mantidas mesmo após o encerramento do programa.

## 🚀 Funcionalidades

* ➕ Cadastro de receitas
* ➖ Cadastro de despesas
* 💵 Consulta do saldo total
* 📋 Listagem das movimentações
* 💾 Salvamento automático dos dados em arquivo JSON
* 🔄 Carregamento das movimentações ao iniciar o sistema
* ✅ Validação de valores inseridos
* ✅ Validação de descrições
* ⚠️ Tratamento de erros durante a entrada de dados

## 🛠️ Tecnologias utilizadas

* **Python**
* **JSON**
* Estruturas condicionais
* Laços de repetição
* Funções
* Listas e dicionários
* Tratamento de exceções com `try/except`
* Manipulação de arquivos

## 📂 Estrutura do projeto

```text
controle-financeiro/
│
├── main.py
├── funcoes.py
└── movimentacoes.json
```

### `main.py`

Responsável pelo fluxo principal da aplicação, interação com o usuário e execução das opções do menu.

### `funcoes.py`

Contém as funções responsáveis pelas principais operações do sistema, como cadastro, cálculo de saldo, listagem e manipulação dos dados.

### `movimentacoes.json`

Arquivo utilizado para armazenar as movimentações financeiras cadastradas.
